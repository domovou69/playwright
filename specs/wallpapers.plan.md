# Wallpapers Section Test Plan

## Application Overview

Scope: the Wallpapers section of zedge.net - list page (`/wallpapers`), header search with the "Wallpapers" filter,
category navigation (header "Categories" menu and the "Explore different wallpaper categories" block at the bottom
of `/wallpapers`), list filters (Category / Tag / Price / Color / Sort by / Reset All), infinite scroll and "Load
more", the wallpaper detail page, free download, and the premium purchase gate.

Constraints:

- Guest user only. Every purchase or sign-in flow stops once the dialog is verified.
- Desktop viewport only (Desktop Chrome project).
- Live production site: `workers: 2` (raised from 1 on 2026-09-27 to speed up runs - see `metrics.md` for the
  known risk this reintroduces, a concurrency-unsafe download test).
- No security testing (XSS, SQL injection, fuzzing) and no load or performance testing.
- Content is live: assert invariants (URL params, badges, prices, counts > 0, href changes), never a specific title
  or exact count. Wallpapers are identified by their `href` (`/wallpapers/<GUID>`); images are not compared.

## Verified facts (used as the test oracle)

1. **Premium gate depends on price.** Price 1, 5, 11, 100, 1000 → detail page shows **"Buy for Ƶ<price>"** →
   modal "To buy this item you need N Zedge Credits" with a credits package selector, a "Log in" link, Cancel and
   Buy Credits. Price **exactly 10** → detail page shows **"Download"** → modal "Unlock and Support the Artist" with
   "Login & Watch Ad" and "Buy Credits". Treated as a bug (see WP-29).
2. **Price filter** has Free / Paid options and a From / To range (URL `minPrice`, `maxPrice`).
3. **Sort by** options: Relevance, Newest first, Price: Low to High, Price: High to Low, Most popular
   (URL `sort=PRICE_ASC` / `PRICE_DESC`, ...).
4. **Category filter is single-select.** Color and Tag allow multiple options.
5. **The URL is the source of truth for filters.** Unchecking an option removes it; editing the URL changes the
   selection. Example: `/wallpapers?sort=PRICE_ASC&minPrice=1&maxPrice=NaN&categories=FUNNY`.
6. **Load more:** after a few auto-loading scrolls a "Load more" button appears; after clicking it, scrolling
   loads more cards indefinitely.
7. **Two category page types:** `/wallpapers?categories=NATURE` (the list page with one category selected) and
   `/category/wallpapers/<slug>` (linked from the "Explore different wallpaper categories" block; a list of
   sub-filters where selecting one changes the heading and the cards).

## Conventions

- Tags: `@smoke` for P1, `@regression` for the rest, `@download` for real downloads, `@bug` for known bugs.
- **Bug tests** assert the **current** (buggy) behavior so the suite stays green, carry the `@bug` tag and an
  annotation `{ type: 'bug', description: '<problem, expected vs actual>' }`. When the site changes, the test fails
  and is reviewed: either the bug was fixed (flip the assertion, drop `@bug`) or the behavior changed again.
- Seed: `tests/seed.spec.ts` for every section.
